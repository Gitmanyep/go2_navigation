## 当前已完成的本地检查

修复运行代码的完整本地回归已通过 256 项：78 项仿真、43 项假控制接口检查、135 项感知/适配器检查。记录在 `logs/20261122_203029_test_86b1debf/`。这些是软件验证，不是实机运动或渲染稳定性验收。

新增不依赖 ROS、不连接设备的对照命令：

```bash
/usr/bin/python3 scripts/benchmark_sector.py --repeats 15
```

默认生成固定种子的 60000 个合成累计点，对整个扇区筛选分别使用旧行排序和新整数键排序；报告保留点是否逐点逐序一致，并保存该主机的耗时。也可对下一次下载的真实 XYZ 文件离线测量：

```bash
/usr/bin/python3 scripts/benchmark_sector.py --points /绝对路径/sector_window.npy --centre 0 0 0 --yaw-deg 0
```

`centre` 和 `yaw-deg` 必须填写该世界系点云对应的参考位置/航向，示例零值仅为占位。工具不推断机身外参。

本次笔记本合成对照：旧方法中位数约 12.02 毫秒，新方法约 5.01 毫秒，约 2.40 倍；保留的 3950 个原始点及顺序完全一致。记录在 `artifacts/sector_offline_resume_20261122/report.json`。这不能换算成 Jetson、RViz 或整机 CPU 的改善幅度。
