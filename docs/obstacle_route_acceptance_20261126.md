# 原厂体素静态路径验收（2026-11-26）

仅使用原厂头下雷达的 odom 体素与位姿，不使用背部 Livox；只输出 RViz 预览，未发送运动指令。

## 根因

同帧实测失败样本中，起点和目标均可用，但起点四邻格全为未知。可达区域仅1格，前沿未知4格、障碍0格、膨胀0格。诊断性允许未知时有路，仅放宽膨胀限制时仍无路。“起点安全”此前只覆盖中心格，机身遮挡造成的脚下缺测仍将起点围住。

## 修复

用户声明安全覆盖当前矩形机身脚下未知格，机身外未知格不放行。已有障碍和安全间距仍保留，中心格依用户声明覆盖。增加可达区域、阻断类型及诊断性放宽对照；对照路线不作为有效路径输出。
